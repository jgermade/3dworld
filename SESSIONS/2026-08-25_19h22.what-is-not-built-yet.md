# 2026-08-25 19h22 · What is not built yet

**This file is the plan.** It is the only open file in `SESSIONS/`, and `## The pending register`
below supersedes every register and every `Next` block in the two `*.completed.md` files beside
it.

It is also a deliberate deviation from the shape `AGENTS.md` describes, and the reason is worth
one paragraph. A session file records a body of work: what was decided, what was learned, what is
not true yet. This one records **no work at all** — it was opened the moment the viewport was
finished, precisely so that the pending register would stop travelling at the end of whichever
file happened to be newest. Two files had already grown four `Next` blocks between them, and the
plan was something a reader had to reconstruct rather than read.

So there is no `Walkthrough · as built` here and there will not be one. When work resumes, it
opens its own file, and the first thing that file does is say which items here it took.

## Where this repo actually was

Six crates, 32 native tests, 8 more against OpenCASCADE, and 17 checks in a real browser.

```
kernel/        w3d-kernel       the seam: 13 methods + the conformance suite    ✅
kernel-fake/   w3d-kernel-fake  the contract without geometry                   ✅
core/          w3d-core         document · history · selection · mesh cache     ✅
kernel-occt/   w3d-kernel-occt  OpenCASCADE through a 13-entry C ABI            ✅ native
                                                                                ⬜ wasm
render/        w3d-render       wgpu · camera · ID-buffer picking               ✅
web/           w3d-web          loader · probe · COOP/COEP · a canvas           ✅ WebGL2
                                                                                ⬜ threaded
app/                            the modeller: a window, a UI, a user            ⬜
kernel-native/                  ours, or truck                                  ⬜
```

The viewport draws in a browser and a click there names a face. Nobody can *model* anything: there
is no UI, no window on the desktop, and `web/index.html` is a harness.

## Verified, and not

Carried forward whole, because it is the half of the record that decides what is worth doing next.
Nothing here is new; it is gathered from the two closed files so that a reader does not have to
open them.

**Verified.**

| | |
| --- | --- |
| `make test` | 32 tests, no setup. Arena identity, document, history, conformance against the fake, mesh packing, camera. |
| `make test-occt` | 8 against OpenCASCADE 7.6.3: the conformance suite, five document tests, and the drilled plate through the GPU. |
| `make wasm` | The default members build for `wasm32-unknown-unknown`, **and** the WebGL2 backend is really in the tree. |
| `make web-test` | 17 checks in Chromium: WebGPU offered, WebGL2 forced, and no COOP/COEP. |
| clippy, fmt | `-D warnings`, no allow-list. Clean. |

**Not verified, and the risk taken with each.**

- **WebGPU has never rendered a pixel, anywhere in this project.** Native tests run on Vulkan
  through lavapipe, which is not WebGPU; the browser's WebGPU is broken in this container. It is
  the largest single unknown, and the *only* thing established about it so far is that a browser
  can claim it falsely.
- **No real GPU has run any of this.** Software rasterisation proves pipelines, layouts, shaders
  and readback. It proves nothing about timing or driver quirks.
- **One browser, one version.** No Firefox, no Safari. Safari matters most and is least likely to
  behave like the one that was tested.
- **A skipped test looks like a passed test.** `w3d-render`'s tests print `SKIPPED:` without an
  adapter and `cargo test` still reports `ok`. `make web-test` is not part of `make test` at all.
- **No geometry is verified beyond the contract.** The conformance suite asserts what must be true
  of *any* correct kernel. Five document tests and a drilled plate are seeds, not a fixture suite,
  and not one of them is degenerate — which is exactly where B-rep kernels fail.
- **The suite still encodes what two backends agree on**, one of which does no geometry.
- **Every performance number in this repository is somebody else's.** Nothing has been measured on
  this workload, because there is not yet a workload.
- **`f32` mesh positions are absolute.** A document kilometres from the origin has lost precision
  before the camera sees it, and the camera's `f64` cannot recover it.
- **The dependency tree has never been licence-audited.** `AGENTS.md` forbids anything
  incompatible with GPL-3.0-or-later and nothing has checked.

## The pending register

**Superseding every register and `Next` block in the two closed files.** Ordered by what blocks
what, not by size.

### Blocking a viewport a person can use

1. **`app/`** — the modeller: a winit window, a swapchain with resize and present, egui drawn in
   the same pass as the scene, and the event loop that turns a drag into `Camera::orbit` and a
   click into `Renderer::pick_begin` → `Document::select`. `Renderer::draw` takes texture views
   precisely so this is the only place that has to change. `web/` already shows what the shell has
   to do; `app/` is the version with a UI in it and a real document behind it.
   It also owns the thing nothing owns today: **the map from `NodeId` to `GpuMesh`.** The mesh
   cache belongs to the document and the GPU buffers belong to the caller, and nothing connects
   them, so an application that does not keep its own map re-uploads every frame.
2. **The threaded variant.** `wasm-bindgen-rayon`, `+atomics,+bulk-memory,+mutable-globals`,
   nightly for `build-std`. The loader already dispatches to it, finds it missing and says so;
   until it is built the two-entry build matrix has one entry and `SharedArrayBuffer` has never
   been exercised.
3. **WebGPU on hardware that works.** See `Verified, and not`. Until then the fast path is an
   argument, and so is every performance claim that rests on compute shaders.

### Blocking the wasm target

4. **An OCCT build for Emscripten.** `kernel-occt` is excluded from `make wasm`, so the browser
   draws a `FakeKernel` bounding box because that is all there is. The toolkit list in `build.rs`
   is the input. Two things must be *decided* rather than discovered: `-fwasm-exceptions` against
   `-fexceptions`, which has real size and speed consequences; and a real upstream pin —
   `native/UPSTREAM` names a version, it does not enforce one.
5. **The tessellation format across the worker boundary.** Hand-waved as "transferable
   `ArrayBuffer`" in the first session and never designed. It now has a fixed point at the GPU
   end — 28-byte interleaved vertices, de-indexed when face ids demand it — so the design has
   something to be designed *against*.

### Owed, but not blocking

6. **A GPU in CI, and a browser in CI.** Two holes of the same shape: a green run today is not
   evidence the viewport works. `apt install mesa-vulkan-drivers` gets lavapipe; `make web-test`
   needs `npm install` in `web/test/`.
7. **A licence audit of the dependency tree** — `wgpu` and about forty transitive crates,
   `wasm-bindgen`/`js-sys`/`web-sys`, and separately Playwright, which is not in the crate graph.
8. **`wasm-opt`, brotli, and a real payload number.** `make web` reports 3.34 MiB of wasm and
   1.12 MiB gzipped today. Both are upper bounds and lazy ones, and OCCT will dwarf them.
9. **Fixture regression with degenerate input** — coincident faces, tangent surfaces, thin walls.
   Where B-rep kernels actually fail, and where OCCT is known to. Still untouched.
10. **truck as the second backend.** The only thing that can say whether the conformance suite is
    right, because it shares no code with either existing backend. Every failure it produces is a
    question about the suite first.
11. **Edges in the kernel contract.** A B-rep modeller is largely judged on its edge display, and
    `Mesh` carries no edge data at all. More visible now that there is something to look at: the
    screenshot is a lit solid with no edges, which is not what a modeller looks like. Declare it
    on the trait first, then implement, then use.
12. **`BRepBuilderAPI_GTransform` has never been exercised.** The non-uniform-transform fallback
    has no test, because nothing in the suite scales non-uniformly. Most likely thing in the shim
    to be wrong.
13. **STEP and IGES.** `TKDataExchange` is one toolkit away and is most of why OCCT was chosen.
14. **Fillets.** `TKFillet` is present. The feature Plasticity is actually good at, so also the
    first honest measurement of the gap — and there is now a viewport to watch them fail in.
15. **Transactions are not user-grouped.** One edit is one undo step, so a drag that transforms
    twenty nodes would be twenty steps. `History::begin`/`commit` already take a label.
16. **No serialisation.** The arena's ids are stable `u32`, which is most of what a format wants.
    There is no format.
17. **Arena compaction.** Slots are never reused, so an arena grows with every node a session ever
    created. Safe only with history cleared, and it renumbers every id. A free list is **not** the
    fix — see the rule in `AGENTS.md` and the bug that produced it.
18. **Measure something.** The 4 GB sharding argument is still an argument. A tessellated body of
    known size through the worker boundary turns it into a number. The payload figure in item 8 is
    a different measurement and does not substitute.
19. **The project's name.** `3dworld` is a directory. Crates are `w3d-` because `3dworld` is not a
    valid Rust identifier. Costs nothing now, costs a rename later.

### Small, and easy to lose

- **The loader's variant probe is a `HEAD` request** for a bundle that does not exist, so every
  page load logs a 404. Harmless, ugly, and it disappears with item 2.
- **`resize` has no test.** It exists and is wired to the browser's resize event; nothing checks
  it.
- **`Renderer::pick` renders a full frame per click.** A pick matrix that shrinks the frustum to
  the pixel is the obvious optimisation and is deliberately unwritten — a click is not a hot path
  and a wrong pick is much worse than a slow one.
- **Instancing.** Every object is a draw call with a dynamic uniform offset. A storage buffer of
  transforms is the natural next step and `Capabilities::vertex_storage_buffers` already says
  WebGL2 will not do it, so it is a two-path feature rather than a free one.
- **No MSAA, no depth prepass, no outline for selection.** Selection is a colour tint.

## Known and deliberately not pending

Not gaps. Each is a decision with a reason, gathered here so that nobody reopens one as a bug.

- **`set_tolerance` does not re-evaluate existing geometry.** Retrofitting a tolerance is a
  rebuild, and a rebuild is a feature that does not exist. Documented at the call site.
- **`Topology` is counts only.** Face ids and edge loops are a widening of the trait; that happens
  when there is a caller, which is item 11 and not before.
- **`OcctKernel` is neither `Send` nor `Sync`.** Correct rather than conservative: `tessellate`
  mutates through `&self` because OCCT attaches triangulations to the faces it meshes. Parallel
  meshing means one kernel per worker, not a lock.
- **`collect_garbage` rebuilds a `HashSet` per call.** Fine at this size, unmeasured at any other,
  and not worth touching before a document is large enough to notice.
- **Nothing is back-face culled.** A solid whose normals are inverted is a defect worth *seeing*;
  culling shows a hole and blames the boolean instead.
- **`render/` does not know what a document is.** Objects carry a caller-chosen `u32`. That is why
  the end-to-end test lives in `kernel-occt/`, and it is the seam working rather than a gap.
- **`w3d-web` is not the modeller and must not grow into one.** Its scene is a fixture. When
  `app/` exists it keeps the surface and the loader glue and loses everything else.
- **The loader's draw check is a heuristic and is meant to be.** A driver that lies cannot be
  detected by asking it, only by looking at what it produced. A document that is legitimately one
  flat colour would trip it, which is why it runs against the fixed startup scene — if `app/` ever
  starts empty, the check has to move.
- **`Renderer::pick` blocks, and is documented as native-only.** `pick_begin`/`collect` is the
  answer for anything with an event loop.
- **Safari's Memory64 status is unresolved.** It blocks nothing, because wasm64 was rejected on
  other grounds. Do not quote a Safari version from these files.
