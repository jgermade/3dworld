# **Pinned by checksum, not by revision.** `native/UPSTREAM` names a version
# and does not enforce one, which the register has held against it since it was
# written; a hash does enforce it. If a fetch fails the check, the file
# upstream changed and somebody has to look at what — not edit the hash.
#
# Nothing here is committed and nothing here is distributed. They are inputs to
# a check, they live in a gitignored directory, and `tools/licences.py` names
# them.
#
