# 2026-08-27 03h55 · Unified Transparent Sub-object Hover & Contextual Selection

## Where this repo actually was

Selection modes (`Body`, `Face`, `Edge`) existed as discrete explicit modes (`SelectionMode`), requiring the user to switch modes manually before picking sub-objects. Hover highlighting over sub-object elements (faces and edges) was not unified.

## Walkthrough · as built

- Extended WGSL shader (`render/src/shade.wgsl`) and renderer (`render/src/lib.rs`) with `hovered_face` uniform parameter.
- Shaded face hover highlights in soft cyan (`rgb(0.35, 0.85, 1.0)`) and edge hover highlights in gold/yellow (`rgb(1.0, 0.85, 0.2)`).
- Extended `Editor` in `app/src/editor.rs` with `hovered_face`, `hover_picked(pick)`, and transparent sub-object selection logic.
- Updated `Scene::objects` in `app/src/scene.rs` to propagate `hovered_face` state into `Material`.
- Added unit test `transparent_subobject_hover_and_picking` in `app/src/editor.rs`.

## Bugs found by building, not by reading

- In `shade.wgsl`, `Object` uniform struct packing requires explicit offset matching across CPU (`write_objects`) and WGSL shader layout. Matching `hovered_face: u32` in the 5th word slot preserved 16-byte alignment without padding.
