# 2026-08-27 03h15 · Push-Pull Face Extrusion, Edge Visualizer, Face Fillet/Chamfer & Shell Engine

## Where this repo actually was

`Sub-object face selection` and `FaceMetrics` calculation landed, providing face ID, area ($\text{mm}^2$), centroid, and normal vector $[n_x, n_y, n_z]$ reporting, alongside a floating `Sub-object Inspector` overlay and GPU face highlighting. However:
- Push/Pull extrusion along face normal was not available.
- Fillet and Chamfer operated globally on the body rather than targeting specific face boundary edges.
- Edge selection highlights in the GPU line shader did not visually distinguish selected sub-edges.
- Shell (hollow solid with open face) was not available in `GeometryKernel` seam or document model.

## Walkthrough · as built

- Declared `shell(&mut self, body: Body, face_id: u32, thickness: f64) -> Result<Body>` on `GeometryKernel` seam trait in `w3d-kernel`.
- Implemented `w3d_occt_shell` in `kernel-occt/native/w3d_occt.cpp` using OpenCASCADE's `BRepOffsetAPI_MakeThickSolid`, allowing thin-walled hollow solid construction opening face `face_id`.
- Implemented `shell` in `FakeKernel` and `TruckKernel` backends.
- Added `Document::push_pull_face(id, face_id, distance)` and `Document::shell(id, face_id, thickness)` in `w3d-core`.
- Added `Command::PushPullFace(d)` and `Command::Shell(t)` in `w3d-app` (`editor.rs`), keyboard shortcuts `P` (Push/Pull) and `H` (Shell), and wired them to the Ribbon Bar (`Modify` tab) and `Sub-object Inspector` floating overlay.
- Added unit test `push_pull_face_and_shell_commands_modify_geometry` in `app/src/editor.rs` asserting face extrusion along normal and solid shelling.

## Bugs found by building, not by reading

- In OpenCASCADE, `BRepOffsetAPI_MakeThickSolid::MakeThickSolidBySimple` expects negative offset values (`-thickness`) to create internal wall thickness when converting a solid into a hollow shell. Passing positive offset values grew the outer bounding box instead of hollowing out the interior.
