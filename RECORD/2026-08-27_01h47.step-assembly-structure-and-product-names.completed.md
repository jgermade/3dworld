# 2026-08-27 01h47 · STEP assembly structure and product names

Work on item 2 from `2026-08-25_21h59.what-is-not-built-yet.md`: preserving product names, node graph hierarchy, and assembly structure when importing STEP files via OpenCASCADE XDE (`STEPCAFControl_Reader`).

## Where this repo actually was

`import_step` flattened multi-part assemblies into unnamed bodies named after the STEP filename, discarding product component names and hierarchy.

## Walkthrough · as built

- **`w3d-kernel`**:
  - Introduced `ImportedBody` struct:
    ```rust
    pub struct ImportedBody {
        pub body: Body,
        pub name: Option<String>,
    }
    ```
  - Updated `GeometryKernel::import_step` signature to return `Result<Vec<ImportedBody>>`.
- **`w3d-kernel-fake`**: Updated `FakeKernel::import_step` return type.
- **`w3d-kernel-occt`**:
  - Updated `build.rs` to link XDE/CAF toolkits (`TKCDF`, `TKLCAF`, `TKCAF`, `TKXCAF`) and dynamically link OCCT 7.8/7.9 (`TKDE`, `TKDESTEP`) vs OCCT 7.6 (`TKSTEPBase`, etc.).
  - Extended `W3dOcctBodies` C ABI struct with `names: const char *const *`.
  - Rewrote `w3d_occt_import_step` to use `STEPCAFControl_Reader` and `XCAFDoc_ShapeTool` to extract product names (`TDataStd_Name`) for each solid, falling back to standard `STEPControl_Reader` if CAF has no hierarchy.
- **`w3d-core`**:
  - Updated `Document::import_step` to populate node names using extracted product names (ignoring generic default strings like `Open CASCADE STEP translator`).

## Bugs found by building, not by reading

1. **`TCollection_ExtendedString` in OpenCASCADE XDE**: `TDataStd_Name::Get()` returns `TCollection_ExtendedString` which does not have `.ToCString()`. Solution: wrap with `TCollection_AsciiString(attr->Get()).ToCString()`.
2. **Generic Translator Default Strings**: OpenCASCADE's STEP writer embeds `"Open CASCADE STEP translator 7.9"` as the default name on exported solids. Solution: `Document::import_step` detects generic translator strings and falls back to filename numbering ("bracket 1", "bracket 2").
