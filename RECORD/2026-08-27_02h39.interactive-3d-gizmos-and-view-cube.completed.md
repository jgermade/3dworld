# 2026-08-27 02h39 · Interactive 3D Transform Gizmos, View Cube, and Selection Modes

## Where this repo actually was

`w3d-app` provided basic mouse orbiting, panning, zooming, and picking on solids. Selecting a body highlighted its mesh, but moving or manipulating it required menu commands. The viewport had no orientation view cube.

## Walkthrough · as built

1. **Camera Alignment & View Cube (`app/src/editor.rs` & `app/src/shell.rs`)**:
   - Added `ViewDirection` enum (`Top`, `Front`, `Right`, `Iso`) and `Editor::align_camera` method.
   - Rendered an interactive **View Cube** floating widget overlay in the top-right corner of the viewport canvas. Clicking `TOP`, `FRONT`, `RIGHT`, `ISO` smoothly snaps the camera orientation.
   - Added **Camera Alignment** controls to the Ribbon `View` tab.

2. **3D Interactive Translate Gizmo Controls (`app/src/editor.rs` & `app/src/shell.rs`)**:
   - Added `Command::TranslateSelection(Vec3)` and `Editor::run` handling using `w3d_core::Document::transform` wrapped in `begin_transaction("Translate")`.
   - Rendered a floating **3D Gizmo Translate** control panel in the bottom-right viewport overlay when solids are selected, offering 3D world axis step translation along +X/-X, +Y/-Y, +Z/-Z with live bounding box feedback.

3. **Sub-object Selection Modes (`app/src/editor.rs` & `app/src/shell.rs`)**:
   - Added `SelectionMode` enum (`Body`, `Face`, `Edge`).
   - Added selection mode toggle buttons (`Body`, `Face`, `Edge`) to the Ribbon `View` tab.

4. **Unit Tests**:
   - Added unit tests in `app/src/editor.rs` for `camera_alignment_commands_update_view_orientation`, `selection_mode_commands_switch_active_mode`, and `gizmo_translate_selection_moves_selected_body_bounds`.

## Bugs found by building, not by reading

- `Vec3` carries `f64` values and implements `PartialEq` but not `Eq`. Deriving `Eq` on `Command` containing `Command::TranslateSelection(Vec3)` failed compilation; deriving `PartialEq` resolved it.
