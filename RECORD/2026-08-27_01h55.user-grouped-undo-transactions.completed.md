# 2026-08-27 01h55 · User-grouped undo transactions

Work on item 15 from `2026-08-25_21h59.what-is-not-built-yet.md`: grouping multi-step edits and drag operations into single undo transactions in `w3d-core` and `w3d-app`.

## Where this repo actually was

`History::begin` asserted that no transaction was currently open, so every primitive edit or transform step was its own separate transaction in `done`. Multi-step operations had no way to group edits into a single undo step.

## Walkthrough · as built

- **`w3d-core::history`**:
  - Added `depth: u32` tracking to `Transaction`.
  - Updated `History::begin` so that when a transaction is already open, `depth` increments instead of panicking.
  - Updated `History::commit` so that `depth` decrements and the open transaction is only finalized to `done` when `depth == 0`.
- **`w3d-core::document`**:
  - Exposed `pub fn begin_transaction(&mut self, label: &'static str)` and `pub fn commit_transaction(&mut self)`.
  - Added integration test `user_grouped_transactions_merge_multi_step_edits_into_one_undo_step` in `core/tests/document.rs`.
