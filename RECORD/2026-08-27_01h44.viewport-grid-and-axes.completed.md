# 2026-08-27 01h44 · Viewport grid and axes

Work on ground plane grid (XY plane at Z=0) and XYZ coordinate origin axes in `w3d-render` and `w3d-app` for spatial reference.

## Where this repo actually was

The viewport rendered solid objects and sharp edge overlays against an empty background, with no ground plane or coordinate axes to orient against.

## Walkthrough · as built

- **`w3d-render`**:
  - Created `Grid` module (`render/src/grid.rs`) with a `LineList` render pipeline.
  - Generated ground plane grid lines (XY plane at Z=0): minor lines spaced 1.0 unit (subtle slate gray), major lines spaced 5.0 units (medium slate gray).
  - Generated XYZ origin axes lines: +X (Red), +Y (Green), +Z (Blue).
  - Integrated `Grid` rendering into `Renderer::draw_into` (drawn before solid faces and sharp edges, togglable via `show_grid`).
- **`w3d-app`**:
  - Added a `Grid` checkbox in the egui side panel to toggle grid rendering.
