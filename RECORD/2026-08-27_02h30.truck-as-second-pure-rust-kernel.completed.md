# 2026-08-27 02h30 · truck as second pure-Rust geometry backend

## Where this repo actually was

The kernel seam `GeometryKernel` in `kernel/` was implemented by `w3d-kernel-fake` (testing backend) and `w3d-kernel-occt` (OpenCASCADE C++ binding). OpenCASCADE is powerful but requires C++ headers/libraries natively and a complex Emscripten build pipeline for WebAssembly.

Item 12 of `RECORD/2026-08-25_21h59.what-is-not-built-yet.md` requested integrating `truck` as a second real B-rep geometry backend. `truck` is a pure Rust CAD/B-rep modeling framework licensed under `Apache-2.0`.

## Walkthrough · as built

1. **New Crate `w3d-kernel-truck` (`kernel-truck/`)**:
   - Implements `w3d_kernel::GeometryKernel` using `truck-modeling` v0.6.0, `truck-topology`, `truck-geometry`, `truck-polymesh`, `truck-stepio`.
   - Primitives: `create_box` (tsweep), `create_sphere` (semicircle wire attachment & rsweep revolution), `create_cylinder` (planar rectangle wire & rsweep revolution).
   - Transformations: `transform` (affinely transformed B-rep solids via `builder::transformed`).
   - Topology & Bounds: `topology` (counts of solids, faces, edges, vertices) & `bounds` (parameter range evaluation on compressed surfaces via `StructuredMesh`).
   - Tessellation: `tessellate` converting NURBS/B-spline surface patches into `Mesh` triangle indices and positions.
   - Persistence: `geometry_format` (`truck-json-1`), `save_body`, `load_body` via `serde_json` serialization.
   - Interchange: `export_step` & `import_step` returning `KernelError::Unsupported` in both directions until truck stepio table parser matures.

2. **Conformance Testing (`kernel-truck/tests/conformance.rs`)**:
   - Runs `w3d_kernel::conformance::run(&mut TruckKernel::new(), ...).assert_passed()`. All 23 conformance checks pass cleanly.

3. **Workspace & Licensing**:
   - Added `kernel-truck` to workspace `members` and `default-members` in `Cargo.toml`.
   - Checked third-party crate licenses (`Apache-2.0` / `MIT`) with `make licences`.
   - Updated distribution notice table with `make notice` (287 crates).

## Bugs found by building, not by reading

1. **Wire orientation and vertex identity in `rsweep`**:
   - Revolving a semicircle arc generated new vertices at the endpoints. Creating a line back to a newly constructed vertex rather than extracting `wire.back().unwrap().ends()` produced an unclosed wire (`FromTopology(NotClosedWire)`), causing `try_attach_plane` to fail.
2. **Symmetric STEP interface requirement**:
   - The seam requires STEP support to be offered in both directions or neither. Declaring STEP export while import returned `Unsupported` failed `conformance.rs`. Returning `KernelError::Unsupported` symmetrically satisfies the contract.
