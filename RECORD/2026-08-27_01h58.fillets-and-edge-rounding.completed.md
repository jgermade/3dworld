# 2026-08-27 01h58 · Fillets and edge rounding

Work on item 14 from `2026-08-25_21h59.what-is-not-built-yet.md`: declaring fillet capability on `GeometryKernel`, implementing `BRepFilletAPI_MakeFillet` in `w3d-kernel-occt`, updating conformance suite, and adding Document/Editor support.

## Where this repo actually was

`GeometryKernel` had no method for filleting or rounding edges. Objects could only be created as sharp primitives or combined via booleans.

## Walkthrough · as built

- **`w3d-kernel`**:
  - Added `fn fillet(&mut self, body: Body, radius: f64) -> Result<Body>` to `GeometryKernel` trait.
  - Added conformance tests in `conformance.rs` verifying that `fillet` returns a new immutable body and that non-positive radii return `KernelError::Degenerate`.
- **`w3d-kernel-fake`**: Implemented `FakeKernel::fillet`.
- **`w3d-kernel-occt`**:
  - Added `"TKFillet"` to `BASE_TOOLKITS` in `build.rs`.
  - Added `w3d_occt_fillet` declaration to `w3d_occt.h` and implemented it in `w3d_occt.cpp` using OpenCASCADE's `BRepFilletAPI_MakeFillet` over `TopAbs_EDGE` loops.
  - Implemented `OcctKernel::fillet` in `kernel-occt/src/lib.rs`.
- **`w3d-core`**: Added `Document::fillet(&mut self, id: NodeId, radius: f64) -> Result<()>`.
- **`w3d-app`**:
  - Added `Command::Fillet` command and keyboard shortcut (`r`).
  - Added "Fillet" button in egui side panel chrome.

## Bugs found by building, not by reading

1. **`TKFillet` Linker Error**: `BRepFilletAPI_MakeFillet` symbols required linking OpenCASCADE's `TKFillet` library. Solution: added `"TKFillet"` to `BASE_TOOLKITS` in `kernel-occt/build.rs`.
