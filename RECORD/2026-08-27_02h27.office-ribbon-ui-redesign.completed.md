# 2026-08-27 02h27 · Office Ribbon UI redesign

## Where this repo actually was

`w3d-app` rendered its chrome in a simple left panel with inline buttons and status line.
However:
- The UI lacked a structured tabbed ribbon toolbar at the top (Office Ribbon UI style).
- Tools (Create, Modify, View, File) were mixed together in a single side panel instead of dedicated ribbon categories.

## Walkthrough · as built

- Redesigned `chrome()` in `app/src/shell.rs`:
  - Defined `RibbonTab` enum (`Create`, `Modify`, `View`, `File`).
  - Added top `egui::Panel::top("ribbon_panel")` with selectable tab headers and grouped action toolbars.
  - Category `Create`: Primitives (`Box [B]`, `Sphere [S]`, `Cylinder [C]`) & Quick Actions (`Fit [F]`, `Select All [A]`).
  - Category `Modify`: Booleans (`Unite [U]`, `Subtract [D]`, `Intersect [I]`), Features (`Fillet [R]`), History (`Undo`, `Redo`).
  - Category `View`: Viewport options (`Ground Grid` toggle, `Zoom to Fit`).
  - Category `File`: Document file ops (`Open...`, `Save`, `Save As...`) & CAD Interchange (`Import STEP...`, `Export STEP...`).
  - Left panel `egui::Panel::left("tree")`: Dedicated Outliner scene graph tree and shortcut reference.
  - Bottom panel `egui::Panel::bottom("status")`: Real-time status text, live modifier key status (`SHIFT`, `CTRL`, `ALT`), body count, uploaded GPU meshes, triangle count.

## Bugs found by building, not by reading

- **Panel Type in egui**: `egui::Panel::top("ribbon_panel")` is the top panel builder in egui (`TopBottomPanel` is not exported at top level).
