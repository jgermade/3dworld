# 2026-08-27 02h36 · Wire w3d-kernel-truck into w3d-web for browser rendering

## Where this repo actually was

`w3d-web` (`web/`) previously used `FakeKernel` (`w3d-kernel-fake`) for its WebAssembly browser loader. `FakeKernel` renders simplified bounding box wireframes.

`w3d-kernel-truck` provides a pure Rust B-rep geometry kernel running natively and in Wasm without C++ toolchains. Wiring `TruckKernel` into `w3d-web` enables real B-rep geometry rendering and interaction in browsers via WebAssembly.

## Walkthrough · as built

1. **`web/Cargo.toml`**: Added `w3d-kernel-truck = { path = "../kernel-truck" }` under `[target.'cfg(target_arch = "wasm32")'.dependencies]`.
2. **`web/src/lib.rs`**:
   - Replaced `FakeKernel` import with `TruckKernel`.
   - Updated `scene()` to instantiate `Document<TruckKernel>`, driving box, cylinder, and transform geometry using the pure Rust B-rep kernel in WebAssembly.
