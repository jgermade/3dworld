# 2026-08-27 03h44 · Interactive Face Extrusion Gizmo Handles & Direct Drag-to-Extrude

## Where this repo actually was

`PushPullFace` and `Shell` commands were available via hotkeys (`P`, `H`) and Ribbon/Inspector buttons with fixed distance/thickness parameters. However:
- Gizmo handles only existed for body-level translation (`TranslateSelection`).
- Selecting a sub-object face in `SelectionMode::Face` did not allow direct mouse drag-to-extrude manipulation along the face's unit normal vector $\vec{n}$.

## Walkthrough · as built

- Extended pointer event system in `w3d-app` (`editor.rs`, `shell.rs`) with `Input::Down` `alt` modifier flag and `drag_face_extrude(dx, dy)`.
- Implemented camera screen-space projection of face normal vector $\vec{n} = [n_x, n_y, n_z]$ in `drag_face_extrude` to convert 2D viewport mouse displacement $(\Delta x, \Delta y)$ into continuous 3D extrusion distance $\Delta d$ in millimetres.
- Triggered direct drag extrusion when dragging mouse in `Face` selection mode or holding `Alt/Option + Drag`.
- Added unit test `interactive_face_extrude_drag_updates_geometry` asserting screen-space drag projection and real-time document geometry updates.

## Bugs found by building, not by reading

- In screen-space vector projection, standard Y coordinate orientation in screen space is inverted relative to camera view plane UP vector ($y_{\text{screen}} = -y_{\text{camera}}$). Correcting the sign of $\Delta y$ ensured dragging the mouse upward on the viewport extrudes positive face height along upward-facing normals.
