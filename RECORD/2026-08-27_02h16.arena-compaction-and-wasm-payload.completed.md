# 2026-08-27 02h16 · Arena compaction and Wasm payload

## Where this repo actually was

`core::Arena` never reused slots so that undo could safely restore nodes into their original slots.
However:
- Deleting nodes left tombstones (`slot.value == None`), causing `arena.slot_count()` to grow with every node ever created (Item 16).
- `make web` built `w3d_web.wasm` but did not measure Brotli compression or offer `wasm-opt -O3` optimization (Item 10).

## Walkthrough · as built

- Implemented `Arena::compact(&mut self) -> BTreeMap<Id<T>, Id<T>>` in `core/src/arena.rs`:
  - Drains empty (tombstone) slots and re-indexes live items into contiguous slots starting at index 0.
  - Returns a mapping of `(old_id, new_id)` so callers can update external references.
- Added `DocumentError::HistoryNotEmpty` and `Document::compact(&mut self) -> Result<usize>` in `core/src/document.rs`:
  - Enforces that history must be cleared (`clear_history()`) prior to compaction to prevent breaking past undo handles.
  - Remaps the active node selection set (`HashSet<NodeId>`).
  - Returns the number of freed tombstone slots.
- Added unit tests:
  - `compaction_removes_tombstones_and_reindexes_surviving_items` in `core/tests/arena.rs`.
  - `compaction_requires_clear_history_and_reclaims_tombstones` in `core/tests/document.rs`.
- Updated `Makefile`:
  - Added Gzip and Brotli compression size reporting to `make web`.
  - Added `make web-opt` target invoking `wasm-opt -O3` when available.

## Bugs found by building, not by reading

- **Compaction History Invariant**: Compacting an arena re-indexes slot positions (e.g. index 3 becomes index 1). If history contains undo steps referencing old slot indices, `Arena::restore` would corrupt memory or fail. Explicitly checking `!self.history.can_undo() && !self.history.can_redo()` and returning `DocumentError::HistoryNotEmpty` prevents compaction while history is active.

## Loose ends, deliberately left

- Compaction is a manual operation invoked when history is cleared; automatic compaction thresholding (e.g. compacting when slot fragmentation exceeds 50%) is not implemented.
