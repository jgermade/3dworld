# 2026-08-27 02h06 · Modifier keys and native file dialogs

## Where this repo actually was

`w3d-app` had basic keyboard shortcuts (`B`, `S`, `C`, `F`, `A`, `Z`, `Y`, `U`, `D`, `I`, `R`, `Delete`, `Escape`) and mouse input (`Left` for orbit/click select, `Middle` for pan, scroll for zoom, `Shift` for additive selection).
However:
- Camera pan was strictly middle-click, with no `Shift + Left Drag` fallback.
- Camera zoom/dolly had no `Ctrl/Cmd + Left Drag` keyboard modifier alternative.
- File operations (`Save`, `ExportStep`) wrote to hardcoded/default paths or required command line options (`--import-step`) because no native OS file picker was integrated.
- The UI had no visual indicator showing active modifier states or shortcuts.

## Walkthrough · as built

- Integrated `rfd = "0.15"` for native OS file dialogs in `w3d-app`.
- Updated `Input` and `Drag` in `w3d-app::editor` to track modifier state (`Shift`, `Ctrl`/`Cmd`, `Alt`):
  - `Shift + Left Drag`: Pans camera across viewport (standard Blender/CAD convention).
  - `Ctrl/Cmd + Left Drag`: Dollies/zooms camera in/out.
  - `Shift + Left Click`: Multi-select toggle.
- Extended `Command` enum to handle native file dialog paths (`OpenPath`, `SaveAsPath`, `ImportStepPath`, `ExportStepPath`).
- Wired `execute_command` in `shell.rs` to open native OS file pickers for:
  - `Open...` (`Ctrl + O` / `Cmd + O`): `.w3d` document selector.
  - `Save` (`Ctrl + S` / `Cmd + S`): Saves to current path or opens Save As picker if unsaved.
  - `Save As...` (`Ctrl + Shift + S` / `Cmd + Shift + S`): `.w3d` document save location picker.
  - `Import STEP...` (`Ctrl + I` / `Cmd + I`): `.step` / `.stp` file import picker.
  - `Export STEP...` (`Ctrl + E` / `Cmd + E`): `.step` / `.stp` export file picker.
- Enhanced egui interface in `shell.rs`:
  - Added button tooltips/hotkey hints (`Box [B]`, `Sphere [S]`, `Cylinder [C]`, `Unite [U]`, `Subtract [D]`, `Intersect [I]`, `Fillet [R]`, `Fit [F]`).
  - Added file buttons (`Open...`, `Save`, `Save As...`, `Import STEP...`, `Export STEP...`).
  - Added active modifier indicator bar in bottom panel (`[SHIFT: Pan/Multi-Select]`, `[CTRL: Zoom]`, `[ALT]`).
  - Added collapsible `"Shortcuts & Modifiers"` guide panel in egui sidebar.

## Bugs found by building, not by reading

- Carrying `PathBuf` inside `Command` variants meant `Command` can no longer implement `Copy`. The startup command loop in `shell.rs` was updated to clone commands (`command.clone()`) rather than dereferencing (`*command`).

## Loose ends, deliberately left

- File pickers run synchronously on the main thread; on desktop this blocks the winit event loop while the dialog is open, which is standard for native dialogs.
