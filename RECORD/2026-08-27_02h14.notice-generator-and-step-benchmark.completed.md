# 2026-08-27 02h14 · Notice generator and STEP benchmark

## Where this repo actually was

`make licences` verified that every linked crate across targets is compatible with GPL-3.0-or-later.
However:
- Serving a `.wasm` build or shipping a binary is distribution under GPL-3. No tool collected or assembled the full license texts, notices, or OpenCASCADE LGPL-2.1 §3 source notices required for distribution (Item 9).
- Performance and memory benchmarks for importing large STEP assemblies (e.g. 15MB assemblies) had never been measured or automated (Item 17).

## Walkthrough · as built

- Created `tools/notice.py` to assemble the distribution `NOTICE` file:
  - Header declaring `3dworld` under GPL-3.0-or-later.
  - OpenCASCADE 7.6.3 LGPL-2.1 §3 source availability notice and repository links.
  - Embedded Font Data notices (epaint_default_fonts: Hack OFL-1.1, Ubuntu Font License 1.0, Noto Emoji MIT/OFL).
  - Iterates 248 third-party crates across `x86_64` and `wasm32` targets, locating license text files (`LICENSE*`, `COPYING*`, `OFL*`) and formatting a 394 KB `NOTICE` file.
  - Supports `--check` mode for automated CI verification.
- Added `tools/benchmark_step.py` to measure STEP import wall-clock duration, peak RSS memory, body counts, face counts, and triangle counts for assembly files.
- Updated `Makefile`:
  - Added `make notice` and `make notice-check`.
  - Added `make benchmark-step`.
  - Added `notice-check` as a prerequisite to `make test`.

## Bugs found by building, not by reading

- `cargo metadata` `--filter-platform` resolves all workspace and third-party dependencies. Local workspace crates (`w3d-*`) must be explicitly excluded so they are not treated as third-party dependencies.

## Verified, and not

**Verified:**
- `make test`: All workspace tests passing, including `notice-check` verification.
- `make test-occt`: All 24 OpenCASCADE tests passing.
- `python3 tools/notice.py --check`: Clean verification of 394 KB `NOTICE` document for 248 crates.
- `python3 tools/benchmark_step.py`: Successfully benchmarked STEP assembly samples (`as1_pe_203.stp`: 1.15s, 0.13 MB; `face_recognition_sample_part.stp`: 0.45s, 2 bodies, 46 faces, 2032 triangles).

**Not verified:**
- Crates whose repository package tarballs do not contain a standalone `LICENSE` or `COPYING` file fall back to stating their declared SPDX license string in the `NOTICE` header.

## Loose ends, deliberately left

- NOTICE file generation requires cargo cache directories on the build host; a completely offline build with no cargo cache requires pre-run cargo fetch.
