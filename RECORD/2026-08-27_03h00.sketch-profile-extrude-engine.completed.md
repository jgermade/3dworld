# 2026-08-27 03h00 · 2D Sketch Profile and 3D Extrude Engine

## Where this repo actually was

The `GeometryKernel` seam supported primitive solid creation (box, sphere, cylinder), booleans, transformations, fillets, and chamfers. Creating custom solids from 2D planar profiles (rectangles, circles, arbitrary polygons) via linear extrusion was not yet declared in the seam.

## Walkthrough · as built

1. **`Profile` Enum & Seam Declaration (`kernel/src/lib.rs`)**:
   - Defined `Profile` enum (`Rectangle`, `Circle`, `Polygon`).
   - Declared `fn extrude(&mut self, profile: &Profile, distance: f64) -> Result<Body>` on `GeometryKernel`.

2. **Backend Implementations (`kernel-fake`, `kernel-truck`, `kernel-occt`)**:
   - Implemented `extrude` on `FakeKernel` (`kernel-fake/src/lib.rs`), `TruckKernel` (`kernel-truck/src/lib.rs`), and `OcctKernel` (`kernel-occt/src/lib.rs`).
   - Added `extrude` conformance test check to `kernel/src/conformance.rs` asserting valid profile extrusion and zero/negative distance validation.

3. **Core Document & UI Controls (`core/src/document.rs`, `app/src/editor.rs`, `app/src/shell.rs`)**:
   - Added `Document::add_extrude` method in `w3d-core`.
   - Added `Command::AddExtrude` and Ribbon UI **`Extrude [E]`** button in the `Create` tab (group `Primitives & Sketches`).
